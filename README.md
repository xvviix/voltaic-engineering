## 🛠 CORE INTERACTIVE EXPERIENCE FEATURES

VOLTA elevates the standard static showcase into an engaging, interactive technical dashboard. Every interactive micro-interaction is custom-built with pure vanilla technologies:

### 1. The Smart-Home Grid Control Center
An immersive, interactive digital cockpit allowing users to act as systems dispatchers. Toggling switches dynamically changes:
- Animated SVG conduit paths pulsing with simulated electrical current flow.
- Real-time room lighting glow states mapped directly onto an architectural villa floor plan.
- The overall active estate load (kW/Amps) with a live safety status dashboard.

### 2. High-Tech Telemetry Oscilloscope
A live-rendered HTML5 Canvas oscilloscope simulating an active AC sine wave grid feed. Features:
- Seamless sinusoidal mathematics representing core current stability.
- Dynamic numerical data fluctuation representing minor real-world variations in voltage (fluctuating around a stable `120.40 V`) and frequency (`60.00 Hz`).
- Real-time power load adjustments reflecting user interactions in the smart-home control center.

### 3. Dynamic Load & Cost Estimator
A client-facing intake tool designed to simulate an engineer's design checklist. Based on property sizes, EV charging configurations, solar installations, and automation desires, the algorithm calculates:
- Projected electrical system load (in kW).
- Minimum structural amperage required (100A, 200A, or 400A).
- Suggested smart panel distribution setup.
- Premium agency-grade budgetary estimations.
- **One-click Injection**: Seamlessly pre-fills the final engineering consultation contact form with customized system specs.

### 4. The "Wire Art" Perfection Slider
A custom-engineered horizontal comparison slider demonstrating the physical difference between standard industry-grade sloppy wiring and the mathematical, color-coded, zip-tied neatness of the **Volta Standard**.

### 5. High-Interactivity Motion Engine
- **Magnetic Fluid Cursor**: A custom dual-element cursor (dot + lag ring) that grows and morphs as it targets interactive navigation, buttons, and switches.
- **3D Card Hover Tilt**: Subtle perspective-based tilting on core capability cards, utilizing mouse coordinate vectors to angle cards dynamically on a 3D plane.
- **Dynamic Portals**: A terminal-style electrical connection link validation on contract submission, displaying dynamic mock system-logs as it processes secure patron registration.

## 🏗 TECHNICAL SYSTEM ARCHITECTURE

The website is engineered strictly as a high-performance, single-page, static application, complying with premium agency and optimization benchmarks.

- **Strict Vanilla Stack**: Built with zero dependencies, external libraries, or modern compile-time bundlers (Pure HTML5, CSS3, and Vanilla JavaScript).
- **Responsive Fluid Grid**: Mobile-first media layout ensuring flawless responsive performance on ultra-wide desktop monitors, tablets, and high-DPI mobile phone screens.
- **Optimal Sandboxed Security**: Fully compliant with offline previews and strictly isolated hosting environments like GitHub Pages. All critical visual components and icons are rendered as embedded SVGs to guarantee immediate load times, perfect crispness, and complete styling flexibility via CSS.
